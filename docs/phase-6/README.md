# Фаза 6: GPS и маршруты

Начата 2026-11-09. Первый срез: ядро маршрутизации без игры, базы и интерфейса.

## 1. Что сделано

Крейт `vexmap-routing` (только `std`, поэтому один и тот же код пригоден и клиенту, и sidecar).

| Часть | Что делает |
|---|---|
| `Graph` | Узлы и нарисованные линии трёх видов: пешком, лодка, поезд. Односторонние линии. Закрытие участка (работы, война, закрытая граница) |
| `Graph::route` | A* по состояниям (узел, вид). Смена вида только в узлах-пересадках, штраф `transfer_penalty`. До 16 остановок по порядку |
| Вне сети | Конец дальше 64 блоков от сети это прямая линия по азимуту (`LegKind::Direct`), если пешком разрешено. Иначе маршрута нет |
| `SpeedTracker` | Скользящее среднее скорости игрока по виду, ограничено 0,5×–2× от стандарта. Мусорные отсчёты игнорируются |
| `Route::hints` | Подсказки поворотов (от 20°): прямо, слегка, поворот, резко, разворот; расстояние от прошлой подсказки |
| `Route::locate`, `Deviation` | Расстояние до линии и пройденный путь. Предложение перестроить после 3 отсчётов подряд дальше 24 блоков. Само перестроение только после подтверждения игрока |

## 2. Решения

### ADR-024. Где строить маршрут

**Статус: предложено, ждёт подтверждения владельца.**

| Вариант | Плюсы | Минусы |
|---|---|---|
| **Клиент по графу от сервера, ядро общее** | Нулевая задержка, работает при падении sidecar, нагрузка на игрока, не на сервер | Нужно раздавать граф, большой граф весит |
| Только sidecar по запросу | Клиент проще, граф не уходит игроку | Нагрузка растёт с числом игроков, нужен канал запроса и ответа |

**Выбор: ядро общее, строит клиент.** Sidecar использует то же ядро для проверки и для запроса из RP-модов. Раздача графа появится вместе с редактором дорог.

## 3. Тесты

`cargo test -p vexmap-routing`: 18 тестов. Проверяются пересадки и их цена, односторонние и закрытые линии, остановки, прямая линия вне сети, отказы на неверных скоростях и числе остановок, подсказки поворотов, отклонение. Сетка 120×120 (14 400 узлов) строит маршрут по диагонали быстрее 5 секунд (порог теста, замера нет).

## 4. Состояние

| Шаг | Статус |
|---|---|
| Ядро: граф, поиск, время, подсказки, отклонение | Готово, юнит-тесты |
| Хранение дорог, рельсов, путей в БД и API | Не начато. Нужны миграции и права |
| Редактор линий в игре (привязка к узлам, типы, закрытие) | Не начато |
| Раздача графа клиенту и подключение ядра к моду | Не начато |
| Текст на экране и 3D-стрелка в мире | Не начато, нужна сборка клиента на стенде |
| Учёт войн и закрытых границ | Только закрытие рёбер. Правила приходят с Фазами 7 и 11 |
| Рельеф при ходьбе вне дорог | Не сделано. Прямая линия не знает воды и обрывов |
| Замер скорости поиска на настоящем графе | Не измерено |
