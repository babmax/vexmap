## Что принято

| ADR | Решение |
|---|---|
| 001 | Регионы мира на отдельных серверах за Velocity. Код с первого дня пишется под много серверов |
| 002 | Форк клиента не делаем. До приёма PR в Horizon разрешён миксин на внутреннюю функцию с пометкой и ссылкой на PR |
| 003 | Транспорт: plugin channel (`native_send_custom_payload_to_player` и `client_packet`), а не `mod_net` |
| 004 | Тайлы: sidecar читает файлы региона через `horizon-world`, живые правки идут через грязные чанки |
| 005 | Панорамы: кадр через путь скриншотов, один небольшой PR на именованный хук, промежуток между гранями |
| 006 | Круглая граница на стороне мода, азимутальная проекция, `θ_max` 120° |
| 007 | Допуск: рукопожатие протокола карты после входа, иначе `native_kick`. `horizon-clients-only` за прокси выключен |
| 008 | Обязательный ресурс-пак через `native_send_resource_pack`, отказ ведёт к `native_kick` |
| 009 | Онбординг: штатный путь через реестр и лончер, инструкция и проверка готовности |

Бюджеты из [adr.md](adr.md#бюджеты-черновик) остаются черновыми до замеров на настоящем коде.
